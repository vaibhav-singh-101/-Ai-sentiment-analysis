
# AI Customer Review Sentiment Analysis

## Project Description
An AI-based customer review sentiment analysis
system built using Python and Machine Learning.

It classifies customer reviews into:
- Positive
- Negative
- Neutral

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit
- Matplotlib
- Joblib

## Features
- Customer review sentiment prediction
- Text preprocessing
- Machine learning model training
- Model evaluation
- Prediction confidence display
- Multiple review analysis through CSV
- Download prediction results
- Sentiment visualization

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Train the model:

   python train_model.py

4. Start the application:

   streamlit run app.py
